# Z-Library 书单增强 v2：设计规格

状态：用户已确认并据此实现为 `2.0.0-dev`。本文是设计目标；实际验证范围及未完成项见 [v2 测试记录](./2026-10-03-booklist-enhancer-v2-test-plan.md)，不能仅凭本文判定功能已在真实站点通过。

## 目标和边界

继续只增强当前已加载的书单条目：显示/隐藏卡片信息，按文件格式、下载状态、出版年份进行本地筛选，并显示加载进度参考值。不请求额外书籍数据，不自动点击 Show more，不保存或恢复阅读断点，不修改下载记录、书单内容或站点排序。现有格式筛选与下载状态保守门控须保留。当前脚本的持久化设置要在升级后继续有效。

本版新增两个精确匹配：`https://z-library.im/booklist/*`、`https://z-lib.fm/booklist/*`。连同现有 `z-lib.sk`、`z-library.sk`、`1lib.sk`、`libb.la`，共六个 HTTPS 书单域名；不恢复 `.biz`，不使用跨站通配匹配。其他镜像仍由用户在脚本管理器的 User matches 中自行添加，并先通过书单结构检测。域名被列入匹配范围不等于已验证其登录后书单兼容性。

## 已核对的站点结构

2026-10-03 在用户提供的已登录 `1lib.sk` 书单页只读核对到：活动容器为 `.booklist-main.active`，条目为 `.readlist-view > z-bookcard`；书卡具有 `extension`、`language`、`year` 属性。桌面与移动端的 Shadow DOM 分别有 `.meta.desktop .idle` 和 `.meta.mobile .idle`，语言与年份目前合成同一段文本；年份未知的样本使用 `year="0"`。书名位于 Shadow DOM 的 `.book-info .title`，内部是轻 DOM 的 `slot="title"`；当前截断由 `max-height: 40px` 和 `overflow: hidden` 造成。书单容器为可换行的 flex 布局，书卡没有固定高度，但展开长书名后的真实布局仍须测试。站点 Show more 当前是 `<div class="page-load-more" onclick="loadMoreBooks(this)"><span class="content">Show more</span></div>`；其元素及原文字必须保留。该书单总数已由先前观察的 774 变为 856，不能硬编码。

## 技术路径选择

采用**保留站点元素、增加脚本专属节点与样式**的方式：书卡元信息仅在用户关闭语言或年份显示时改写对应的文本节点，保存原文并在重新开启时精确恢复；长书名通过每张卡 Shadow DOM 内的脚本专属样式解除截断；筛选统计与页数进度使用脚本专属元素。备选的整卡重建会破坏站点事件与 Shadow DOM 行为；纯 CSS 叠盖语言/年份文字则容易造成重影、辅助阅读和响应式问题，因此均不采用。

## 浮窗结构与即时设置

标题栏显示“书单增强”、齿轮和折叠按钮。主界面按以下两组排列：

| 分类 | 开关 | 默认值 | 作用 |
| --- | --- | --- | --- |
| 信息显示 | 固定显示文件格式标签 | 开（保留旧设置） | 维持现有静止态格式标签 |
| 信息显示 | 语言 | 开 | 关时隐藏书卡当前显示的语言，桌面/移动端一致 |
| 信息显示 | 年份 | 开 | 关时隐藏书卡当前显示的出版年份 |
| 信息显示 | 完整显示超长书名 | 关 | 解除两行截断，允许卡片随内容增高；不改书名、链接或列宽 |
| 筛选器 | 只显示指定文件格式 | 关（保留旧设置） | 使用现有多选规则 |
| 筛选器 | 只显示指定下载状态 | 关（保留旧设置） | 使用现有仅已下载/仅未下载规则及等待门控 |
| 筛选器 | 只显示指定年份的书籍 | 关 | 使用设置中的上下限和缺失年份例外 |

筛选器开关后始终以括号显示当前**已生效**规则，例如`（epub）`、`（仅未下载）`、`（2010–2020）`。规则为空显示`（请手动设置）`；冲突显示`（设置冲突）`。格式选项很多时可在可见文字中缩略为“前几项等 N 项”，但完整规则必须可通过提示文字或辅助阅读取得。下载记录尚未确认时，开关仍置灰、保留勾选意图和等待图标；规则文字不冒充筛选已生效，控件旁明确提示“等待/暂停”。

齿轮只切换设置区的可见性，不再承担提交动作。设置区用独立的浅色背景、边框、缩进和标题与主开关区区分，保持可读对比度、键盘焦点与窄屏内部滚动。设置区的多选框、复选框、下拉框切换后立即保存并安排一次刷新；自定义格式与年份文本输入停顿约 250 毫秒后自动应用，按 Enter 或离开字段立即应用，字段旁注明此行为。收起设置区时刷新任何待处理输入，但不需要确认按钮。

### 年份规则

最小值和最大值都是可留空的文本输入，非空时只接受 `1` 到 `9999` 的十进制整数，范围**包含端点**。只填最小值表示 `≥最小值`，只填最大值表示 `≤最大值`，相等表示仅该年。`year="0"`、缺失属性和无法解析的属性都归为“年份缺失”。在有效年份范围内，它们默认不显示；设置区新增默认关闭的「显示年份缺失的书籍」，开启后作为范围之外的例外保留。该选项仅在年份筛选开启且范围有效时影响结果。

两端都空时年份筛选暂不应用，提示`请手动设置`，不隐藏任何书；仅勾选“显示年份缺失的书籍”不构成范围。非整数、超出 `1–9999`、最小值大于最大值等冲突时显示具体错误，年份筛选暂停（fail-open），保留原输入供修正；其他有效筛选器继续工作。年份设置文本在输入提交时持久化，不能因冲突而悄悄恢复旧范围。

### 卡片信息的可逆改动

从书卡属性读取语言/年份；桌面与移动端各自保留原 `.idle` 文字，用其原有语言写法或缩写重组**需要显示**的部分，不从书名或悬停文本猜测。关闭其中一项时只改文字节点，不移除原容器、原站点的悬停内容或脚本的格式标签；重新开启时恢复站点原文。卡片替换、属性更新和 Shadow DOM 延迟建立时重新核对；若结构不兼容，不破坏原元数据并在相关开关旁提示。书名展开样式只作用于脚本标记的卡片，关闭后恢复站点原有两行限制。

## 一次筛选、统计卡与 Show more

所有筛选器开关只修改设置并请求一次合并刷新。每轮刷新先枚举活动书单里的**真实** `z-bookcard`，预先解析格式集合、年份范围和下载门控，再对每张卡一次性计算三项条件的交集、更新脚本专属隐藏类、得到 `X`（已加载）与 `Y`（本工具筛选后）。等待或冲突的某项筛选暂停，不阻断其他有效条件；`Y` 不宣称包含站点原生搜索/隐藏效果。DOM 更新、Show more 追加和同一帧的连续设置变化须合并，不能每个开关各自扫描一次书单。

只要任一筛选器开关开启（即使该规则为空、冲突或等待中），就在 `.readlist-view` 最后加入一张**外观像书卡、实际为普通元素**的统计卡。它显示“当前已加载 X 本；本工具筛选后 Y 本；书单共 T 本”，并在规则暂停或总数不可读时用就地提示说明；无可见书卡时统计卡仍单独出现。`Y` 只反映当前确实生效的筛选条件。它不带 `z-bookcard` 标签，不参与书籍数量、筛选、站点下载检测或书卡点击。所有筛选器关闭时移除统计卡。浮窗原有统计区及底部状态栏删除；下载等待、格式/年份冲突、信息显示兼容错误改为对应控件旁的提示，不增设另一个全局状态栏。下载状态等待超过 30 秒或取回失败时，就地提示用户刷新页面或检查登录状态，但不把未知书籍判作未下载。

只要站点的 `.page-load-more` 存在，保留其 `.content` 和原 `onclick`，在原“Show more”文字之后添加可更新的脚本专属进度文字（视觉上可换行）：`约展开 N 次，当前约第 C 页，尚未加载约 R 页，书单总长度约 P 页`。`C=ceil(X/20)`，`N=max(C-1,0)`，`P=ceil(T/20)`，`R=ceil((T-X)/20)`；它们是每批约 20 本的估算，不是实际点击记录、URL 页码或断点。`X=0` 时当前页显示“尚无已加载书籍”，不显示“第 0 页”；`T` 缺失或小于 `X` 时，对无法可靠计算的字段显示“未知”，不得出现负数/NaN。原按钮被站点替换时重新附加脚本文字，不覆盖加载中或失败的站点原文。**按钮消失后，不再另设页数进度提示**。

## 折叠、拖动与停靠

浮窗每次加载默认展开。标题栏右侧依次为齿轮和折叠按钮；展开时按钮为开口向上的 V，折叠后为开口向下的 V，页面只留下标题栏。按钮需有文字 `aria-label`、`aria-expanded` 和明显焦点样式。折叠时隐藏主开关与设置区，但不改变任何生效中的筛选；再次展开恢复先前的设置区开闭状态。折叠状态不持久化。若已折叠时点击齿轮，则展开浮窗并打开设置区。

拖动只从标题栏非按钮区域开始，支持鼠标/触屏指针；松手后停靠最近的**视口**边缘，同时限制在视口内，不允许标题栏完全移出屏幕。停靠边及沿边位置可作为 UI 偏好保存（不是阅读断点），窗口缩放后重新钳制。桌面初始位于右上；窄屏若无已保存停靠位置，初始在书单前的文档流中以免遮挡，首次拖动后切换为视口内浮动。设置区提供立即生效的“重置浮窗位置”，防止用户把面板留在不便操作处。拖动不能触发齿轮/折叠按钮，也不能触碰书卡或 Show more 的事件。

## 验收与未验证边界

发布前需通过配套测试方案中的自动化和本地浏览器夹具，并用实际脚本管理器在已登录书单完成至少一次人工验收。当前只核对了 `1lib.sk` 的 DOM；其他五个匹配域名的首页或书单页面不能据此视为等价。下载映射为空时成功与失败仍无法可靠区分，继续暂停下载筛选；不能因本次改版把“未知”推断为“未下载”。不得持久化书籍标题、ISBN、下载映射、页面令牌或浏览进度，也不引入外部请求。
