# Z-lib Booklist Enhancer v3：设计与验收规格

状态：设计已在对话中分段确认；本文描述待实现的 v3，不代表脚本现已具备这些功能。现有 `2.0.1-dev` 的实现与未完成验收见 [v2 设计](./2026-10-03-booklist-enhancer-v2-design.md)和 [v2 测试记录](./2026-10-03-booklist-enhancer-v2-test-plan.md)。

## 目的与范围

把现有书单增强脚本扩展为六个已知 Z-Library 域名上的轻量站内工具：书单页保留并扩充筛选/显示面板；其他页面至多显示一次短暂的启用提示。所有工具界面支持多语言。书单页增加作者名展开、统计卡视觉优化，以及两项明确由用户触发的自动化操作。批量收藏本版只显示禁用的「开发中」入口，不执行收藏。

继续遵守 v2 的边界：筛选对象仅为当前已经加载的真实书卡；不预先加载全部书单，不自动恢复断点；下载状态未确认时不推断为未下载；不复制或持久化书籍链接、标题、下载映射、页面令牌和浏览进度。除用户明确点击自动化按钮外，不自动点击站点控件、不打开书页、不修改账号收藏。

## 已观察的站点事实与方案选择

截至 2026-10-04，已登录的 `1lib.sk` 示例书单有 `.booklist-main.active .readlist-view > z-bookcard`，书卡的书页地址在宿主 `href` 属性；作者显示在开放 Shadow DOM 的 `.author`，原站为它设置固定高度、`white-space: nowrap` 和溢出省略。本站书卡右键菜单能显示「Add to Favorites」；对两张测试书卡分别加入及取消后，菜单会在加入/取消之间切换，卡片的 `favorite` 属性可变成字符串 `true` 或 `false`。初始未操作的书卡可能没有该属性，因此不能简单把属性缺失视为未收藏，更不能盲目批量点击这一**切换操作**。测试中两本均已执行取消；其中第一本在刷新后再次显示「Add to Favorites」。这只证明本站人工操作路径存在，不证明可安全批量化或其他域名等价。

采用一个可安装的用户脚本，在现有文件里分出启动路由、提示窗、翻译、书单面板和自动化任务等内部模块/函数，并为纯逻辑编写单元测试。备选的两个独立脚本会使安装与设置迁移变复杂；跨全部网站匹配再探测书单会扩大不必要的注入范围，因此不采用。只在六个已知域名全站匹配，再依据 URL 和书单结构分流；用户手动添加的其他镜像继续受结构门控。

## 名称、域名与启动路由

脚本元数据 `@name` 与浮窗标题统一为 **Z-lib Booklist Enhancer**，不随语言变化。使用名词 `Enhancer` 而非动词 `Enhance` 或泛称 `Helper`；简介可以同时提及 `Z-Library`，但不承诺市场搜索排名。

六个 `@match` 为 `https://z-lib.sk/*`、`https://z-library.sk/*`、`https://1lib.sk/*`、`https://libb.la/*`、`https://z-library.im/*`、`https://z-lib.fm/*`。这表示这些主机的首页及各路径，而不是只匹配根路径；不加入 `.biz`、HTTP 或任意域名通配符。其他镜像仍由用户在脚本管理器添加 User matches；说明中的示例改成完整站点路径匹配，另说明仅匹配书单路径也可使用书单功能。

书单路径 `/booklist/…` 首先等待现有书单结构指纹，成功才启动完整面板。站点迟迟未提供结构时，最多等待 30 秒后安静退出，不把加载失败误判成普通页面。六个内置主机的其他路径只启动提示窗，不安装书卡观察器、筛选 CSS 或面板；`/booklists` 为书单目录，仍属普通页面。用户自加镜像只有在书单结构指纹成立时才可启动完整面板，其他路径保持静默，避免在错误匹配的第三方站点出现推广提示。书单页启动成功也标记本次标签页会话已经了解工具，之后同标签页同域名不再显示提示。

元数据加入 `@noframes`，运行时再用顶层窗口检查兜底；嵌入框架中的同域页面不创建第二套界面或提示。启动函数须可重复调用而不重复安装界面/监听器：从浏览器前进后退缓存恢复时，由 `pageshow` 的 `persisted` 状态重新检查路由、DOM 和已被 `pagehide` 清理的观察器。若站点在同一文档内切换 URL，优先用脚本管理器支持的 `urlchange` 信号重新分流，并兼容 `popstate`/`hashchange`；不侵入式重写站点的 `history` 方法。每次响应面板操作前也核对当前 URL 和书单容器是否仍属于初始化时的书单，不符合即停用旧面板；无法可靠观察的同文档跳转允许用户刷新页面，但不能用旧面板操作另一书单的 DOM。

## 非书单页提示窗

提示窗固定在视口右上，不能拖动、停靠或调整位置；只含产品名、简短启用说明、站内 `/booklists` 链接、关闭按钮及其下方默认未勾选的「不再显示该提示」。在 `/booklists` 本页改为「打开任意书单即可启用」，不显示指回自身的链接。关闭按钮显示剩余秒数（例如「关闭 · 10s」），插入后开始十秒倒计时，结束时移除；手动关闭立即移除。倒计时暂停或后台标签页计时延迟时，以实际截止时间计算，不出现负数。

同一标签页、同一域名的会话中最多提示一次；采用该站点的 `sessionStorage` 保存已显示标记，不做跨标签页同步。若存储不可用，仅在当前页面内去重，并容许下次导航重新提示。「不再显示」勾选后立即把当前域名加入脚本持久化的关闭列表；其他域名不受影响。书单页设置区提供「在本站显示启动提示」以撤销该域名的关闭状态；取消关闭不强制在当前页弹窗，之后符合条件的会话再显示。持久化仅保存主机名与布尔值，不保存访问历史或完整 URL。

浏览器复制标签页或新页面保留 `opener` 时，`sessionStorage` 可能复制初值；此时提示可能被视作已显示，不承诺跨标签页恰好各显示一次，也不为此加入跨页协调。后台计时器可能延迟执行，提示窗以绝对截止时间计算；标签页重新可见及 `pageshow` 时立即检查过期并移除，避免批量打开的后台书页日后被激活时才出现过期提示。

边框以蓝色高亮闪烁两次后回到静态样式；`prefers-reduced-motion: reduce` 下不播放动画而使用静态强调边框。`prefers-color-scheme` 分别提供浅色/深色背景、边框、文字及焦点样式。提示窗与书单主面板各自处于隔离样式范围，不修改站点原生页面。

## 国际化

支持 `en`、`zh-CN`、`zh-TW`、`fr`、`de`、`ru`、`ja`、`ko`、`es`、`pt-BR`。设置中增加「界面语言」选择，第一项为「跟随浏览器/系统」，默认选中；浏览器只能提供其报告的首选语言，不能直接读取操作系统语言。按 `navigator.languages` 顺序匹配支持项；`zh-HK`/`zh-MO` 映射到繁体中文，其他未明确支持的中文地区映射到简体中文，`pt` 映射到巴西葡萄牙语，其余可匹配基本语言；都不匹配时回退英语。手动选择立即重绘文案并持久化为脚本全局偏好，保持现有筛选和表单值，不重新加载页面。

所有**工具生成**的可见文字及 `title`、`aria-label`、占位符、规则摘要、等待/错误信息、统计卡、Show more 附加进度、提示窗倒计时和自动化确认/结果均通过同一翻译表及带命名参数的模板生成。翻译键必须在十个语言包中齐全；运行时缺项回退英语，不显示原始键名。数字依当前界面语言用 `Intl.NumberFormat` 格式化。书籍标题、作者、站点原生 Show more 文案和站点原生菜单文字不翻译、不替换；书单页原有筛选语义与设置持久化字段不因切换语言而变化。产品名称在全部语言中固定为英文。

## 书单面板与卡片显示

主界面顺序为「筛选器」→「信息显示」→「自动化（beta）」→ 独立视觉区域中的设置项。筛选器及其规则、下载等待门控、统一的一轮筛选、Show more 估算、折叠/拖动停靠与 v2 保持不变；重排不能造成重复筛选或丢失旧偏好。

信息显示新增默认关闭、独立于长书名开关的「完整显示超长作者名」。启用时只对真实书卡的 Shadow DOM 增加脚本专属样式，解除 `.author` 的单行截断与固定高度，同时使 `.book-info` 高度可随内容增长、保留原先 88px 的最小高度。只打开书名、只打开作者、两者都打开、两者都关闭四种组合都要正确；关闭两个开关后恢复原站布局。不改作者文本、作者链接、书卡宽度或点击行为。书卡替换/延迟建立 Shadow DOM 时可重施样式；结构不兼容则保留原站卡片并在相关开关旁提示。

筛选器开启时沿用末尾的 `.zble-summary-card`，仍是普通元素而非 `z-bookcard`；用三组纵向指标显示「当前已加载 X 本」「本工具筛选后 Y 本」「书单共 T 本」。标签较小、数字较大，允许换行；跟随当前真实书卡的 flex 宽度、最小高度、圆角、背景及阴影，同时保持足够对比度和深色模式。无筛选结果时仍显示；总数未知时明确写「未知」，不虚构数字。卡片不参与书籍计数、自动化目标或站点事件。

## 自动化（beta）

三个按钮依次为「连点 5 次 Show more」「打开当前视图的所有图书页面」「批量加入收藏 · 开发中」。自动化任务只响应用户明确点击；执行期间按钮禁用，状态/错误就地显示在自动化区，不恢复旧的全局状态栏。语言切换不会重启或重复执行任务。

### 连点 5 次 Show more

逐次重新定位站点原按钮并调用其原生点击路径，等待真实书卡数量增长且该批追加结束，或按钮消失后才进入下一次，最多执行五次。不能以第一张新书卡出现就判定整批完成；应结合按钮的加载/禁用状态和书卡数量的短暂稳定期，无法确认批次结束则按超时停止，避免请求重叠。不直接调用或重写站点私有加载接口，不统计为用户真实点击历史。原按钮消失、无可加载内容、单次等待超过 20 秒或出现异常时停止，报告已完成次数及原因；在已有任务进行时不允许重复启动。书籍筛选隐藏的卡片仍计入加载增长判断，不能以筛选后可见数判断加载成功。

### 打开当前视图的所有图书页面

在设置中为**当前域名**手动打开此能力，默认关闭；按钮不可用时说明原因。任何已经打开、但仍在等待下载状态或存在空规则/冲突规则的筛选器，都会暂时禁用这一高风险按钮，避免把尚未真正筛过的书误当作目标；下载筛选开启时若仍有无法分类的书卡，也先禁用。点击时取当前已加载、经本工具筛选后**实际可见**的真实书卡快照（同时排除站点自身隐藏的卡片），从宿主 `href` 构造同源 `/book/` 链接，去重且剔除无效/跨域链接；无有效目标时不弹确认。不设 50 本或其他数量硬上限，不保存打开历史、断点或书籍 URL。

两次本工具确认连续通过后才调用 `GM_openInTab` 在后台逐本打开，并按适度间隔提交以保持源页面可响应；每条链接只尝试一次，异常不盲目重试以免重复标签。确认使用脚本自带、可键盘取消和明确管理焦点的对话层，不依赖可能被浏览器抑制的原生 `window.confirm()`。确认文案保持短句：

1. 「将打开 X 个页面，可能卡顿或触发站点限流。继续？」
2. 「已打开的页面无法批量撤销。风险由你承担，确认执行？」

`X` 是经校验和去重后的准确目标数。任一确认取消时零操作。第二次确认后、首个开页请求前再次确认源书单和目标快照仍有效；若卡片、筛选结果或权限已变化，取消本轮而不静默替换目标。若同一源页面已执行过一次，本页内再次点击时第一层确认追加简短提醒「本页已执行过，可能重复打开 X 个页面」；仍保留两次确认，但不保存跨页面历史或书籍清单。若缺少 `GM_openInTab`、源页面被关闭、浏览器拒绝或单条调用失败，分别禁用/停止/计为失败，不声称全部完成；界面显示已尝试、已提交打开和失败数量。`GM_openInTab` 返回或未抛错只代表提交了开标签页请求，不代表目标页加载、登录或访问成功；不以 `window.open()` 绕过脚本管理器或浏览器限制。工具不提供暂停或批量关页按钮，也不自动重试失败项（重试可能重复打开已成功的书）；但不宣称浏览器操作绝对不可中止。此操作可能打开数百个标签页，默认禁用与双重确认是用户选择门槛，不是资源风险消除保证。

### 批量加入收藏：本版延期

本版仅显示禁用按钮和「开发中」说明；不扫描收藏、不发收藏请求、不触发确认弹窗。延期原因不是原站没有收藏入口，而是初始书卡不能可靠表明已收藏状态，菜单动作有加入/取消两态；逐本判断、等待服务端结果、错误恢复和多语言站点适配需要独立验证，仓促执行有取消已有收藏的风险。

将来若实现，必须只处理当时筛选后可见的真实书卡，跳过已经收藏的书，使用原站可验证的操作而不是臆测私有 API，并在任何修改前确认：「将处理当前视图的 X 本书；无法批量撤回，误操作需逐本取消。继续？」这里 `X` 为待检查书卡数，不假称全部都会新增收藏。本版不实现这段未来行为。

## 设置兼容、安全与失败边界

沿用 `zble-settings-v2` 的有效字段和现有用户偏好；增加语言及按域名的高风险能力/提示关闭偏好时做输入清洗和默认值回退，不重置格式、年份、下载、停靠设置。脚本存储可用时即时保存；存储失败时当前页仍可工作并明确提示偏好未保存。书单结构、Shadow DOM、书页链接或站点控件不符合预期时局部停用相关能力，不破坏原生页面。既有下载门控仍等待 `marksLoaded`，30 秒超时不能把未知状态当作未下载。

不添加外部 GIF、翻译服务、分析服务或远端依赖；资源和账号风险只由用户点击自动化按钮触发。测试夹具与日志不得包含登录令牌、页面原始书卡 HTML、个人账号资料或完整私有链接。

## 跨浏览器与脚本管理器边界

首轮支持目标为桌面版当前稳定 Chrome、Firefox、Edge 搭配 Tampermonkey；三者分别验收，不能以 Chrome 通过推定 Edge 或 Firefox 通过，也不宣称旧版浏览器、移动端或其他脚本管理器已兼容。Chromium 的 Manifest V3 与 Firefox 的 Tampermonkey 注入模式可能给出不同的实际启动时机，`@run-at` 仅指定尽早运行：启动时检查 `document.readyState` 和已存在的书卡/下载标记，事件监听与现状扫描结合，不假定 `DOMContentLoaded` 或站点的 `marksLoaded` 一定发生在注入之后。尤其整页都未下载且 `marksLoaded` 已在注入前触发时，单凭空标记无法证明状态已取回；下载筛选继续显示等待/超时，不把空集合解释成「全未下载」。

在三个浏览器分别确认 `@noframes`、Shadow DOM 样式注入、`GM_openInTab` 授权及后台开页行为、浏览器返回缓存、后台计时、域名偏好和语言跟随。`GM_openInTab` 的可用性受脚本管理器、扩展权限及浏览器设置影响；不可用时禁用按钮并给出原因。样式不以 `:has()` 等增强选择器作为功能正确性的唯一条件；深色模式之外，还要在强制高对比度模式保证边框、焦点、开关和禁用态可辨。浏览器缩放到 200%、窄视口、长单词/长译文时，对话层、提示窗、主面板和统计卡须可滚动/换行，不遮住确认或关闭按钮。

参考依据：[Tampermonkey 注入模式](https://www.tampermonkey.net/documentation.php?ext=d2&q=content_script_api)、[Tampermonkey `@run-at`](https://www.tampermonkey.net/documentation.php?locale=en&q=run_at)、[Tampermonkey `@noframes`](https://www.tampermonkey.net/documentation.php?ext=iikm&q=noframes&version=4.16.1)、[Tampermonkey `GM_openInTab`](https://www.tampermonkey.net/documentation.php?locale=en&q=GM_openInTab)、[MDN `pageshow`](https://developer.mozilla.org/en-US/docs/Web/API/Window/pageshow_event)、[MDN `sessionStorage`](https://developer.mozilla.org/en-US/docs/Web/API/Window/sessionStorage)、[MDN `confirm`](https://developer.mozilla.org/en-US/docs/Web/API/Window/confirm)、[Chrome 后台标签页计时](https://developer.chrome.com/blog/background_tabs)、[MDN 强制高对比度](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/%40media/forced-colors)。

| 领域 | 验收点 |
