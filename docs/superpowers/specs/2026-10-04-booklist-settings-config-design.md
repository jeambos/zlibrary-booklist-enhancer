# Z-lib Booklist Enhancer：设置、筛选配置与自动化反馈设计

状态：用户已批准实施；对应脚本版本为 `3.1.0-dev`。独立审阅后安全修订：实际站点的按钮禁用机制仍未核实，手动重置仅在带显式标记的本地夹具中启用；真实域名卡住时入口保持禁用并提示刷新。Node 自动化测试与真实浏览器验收边界以 [v3.1 测试记录](./2026-10-04-booklist-v31-test-record.md)为准；本文不是跨浏览器验证报告。现有 v3 行为以 [v3 设计](./2026-10-04-booklist-enhancer-v3-design.md)为基线。

## 目标与边界

让用户一眼区分工具的全局设置（setting）与每个筛选器的规则配置（configuration）；信息显示开关不增加配置。自动化按钮直接承载运行状态和 Show more 的累计点击结果，不再用 Show more 按钮下方的状态段落。保留现有格式、下载状态、年份筛选语义、即时生效规则、下载等待门控、批量开页两次确认和收藏「开发中」行为。现有 `zble-settings-v2` 与逐域名偏好继续有效，不清空用户已选规则。

本版仍是一个无需构建的 Userscript，版本递增为 `3.1.0-dev`；所有新增工具文案覆盖现有十种界面语言。浏览器真实验收未完成前保留 `-dev`。

## 设置与配置的划分

标题栏右上角原齿轮改为一致的单色扳手 SVG，名称/提示为「全局设置」。扳手只展开全局设置：界面语言、本站启动提示、本站批量开页授权、重置浮窗位置、镜像 User matches 说明，以及「关于」。关于栏目用一句话介绍本项目，例如「为 Z-Library 书单提供灵活筛选、信息显示和自选自动化操作。」；开发者和 GitHub 暂显示本地化的「待填写」纯文本，不创建虚假链接或占位 URL。

三个筛选器的文案旁各有独立齿轮 SVG 按钮，分别展开本条下方的内联配置：

| 筛选器 | 配置内容 |
| --- | --- |
| 文件格式 | PDF、EPUB、AZW3、MOBI、其他全部、自定义多选；自定义文本框及原有提示 |
| 下载状态 | 仅未下载／仅已下载 |
| 年份 | 最小年份、最大年份、显示年份缺失的书籍、输入生效提示 |

点击任一配置齿轮只展开/收起配置，不切换旁边的筛选开关；筛选开关只改变是否参与筛选。下载状态尚未取回、对应筛选开关置灰时，配置齿轮仍可打开以预设规则。最多展开一个配置区域：打开另一项或全局设置时先关闭当前项；再次点击同一按钮则收起。折叠整个面板时暂存当前展开状态，不改变筛选规则。配置和全局设置在视觉上用不同标题、边框/底色区分；齿轮/扳手均有 `aria-label`、`aria-controls`、`aria-expanded` 与可见键盘焦点。文本输入沿用停顿约 250 毫秒或回车生效，并在收起对应配置时冲刷未提交输入。所有开关与选择仍即时生效。

信息显示区仅保留五个开关、没有齿轮。文案改为「文件格式标签」「书籍语言（页面自带）」「书籍年份（页面自带）」，长书名和长作者名文案不变。十种语言均表达“页面自带”与“工具增补标签”的区别；标签的实际显示/隐藏行为不变。

## Show more 按钮状态与累计计数

初始文案仍为「连点 5 次 Show more」。每次任务执行时显示「[运行中] 连点 5 次 Show more」；任务停止后显示「连点 5 次 Show more [已点 X 次]」。如果累计加载失败次数 `Y > 0`，改为「连点 5 次 Show more [已点 X 次，失败 Y 次]」；`Y = 0` 时完全不显示失败字段。`X` 是当前书单页面内本工具对原站 Show more 按钮实际发出的点击尝试总数，不是启动自动化的次数或成功加载批次数；`Y` 是这些点击中未能完成该轮加载的次数。二者跨同一页面上的多次自动化运行累计，刷新、离开或切换书单后归零，不持久化。

一次点击在观察器建立并即将调用原站 `click()` 时记入 `X`；若该次调用抛错，或点击后该批连续 10 秒没有真实新书卡，记入 `Y`。按钮在点击前已不可用、用户导航离开/关闭页面、中途取消，以及按钮消失且末批不足 20 本但已稳定并到达书单末尾，都不算「加载失败」。若脚本无法明确判断结果，保守停止且不虚构成功或失败。现有 `runShowMoreFive` 须单独报告实际点击尝试和失败批次，不能把现有的 `completed` 批次数当作点击次数。移除 Show more 按钮下方的可见状态统计；失败原因可在按钮的 `title`/无障碍描述中给出，不能用 `Y` 掩盖原因。原站 Show more 上附加的页数估算仍保留，与此累计计数相互独立。

每轮从调用原站按钮开始，以最后一次真实书卡数量增长为基准计时。未满 5 秒时显示「[运行中] 连点 5 次 Show more」；达到 5 秒时显示「[可能失败，X 秒后放弃] 连点 5 次 Show more」，`X` 从 5 递减到 1。新增真实书卡会立刻恢复「[运行中]」并重新计时；工具生成的统计卡、页数文字或其他 DOM 变动不算进展。连续 10 秒无进展即停止本次五连，不进行下一次点击。后台标签页计时被浏览器延迟时，以绝对时间重新计算倒计时，不补点、不显示负数。此无进展保护替换旧的单轮 20 秒固定超时；正常达到 20 张且稳定、或末轮按钮消失并稳定的判定仍保留。

## 原站 Show more 卡住后的手动重置

在自动化区增加「重置 Show more 按钮可用性」按钮，始终可见、默认禁用。它只在同一活动书单上观察到一次**实际发起**的 Show more 操作（用户点击原站按钮或工具五连点击），之后连续 10 秒没有新增真实书卡，且原站按钮仍存在并确实不可用时，才变为可点击。仅仅看到原站按钮初始不可用、长时间未点击、按钮已消失、书单已经切换或达到末尾，都不足以判定卡住。手动点击原站按钮也须纳入观察，但不计入工具的累计 `X/Y`。有新书卡加入则重置观察时钟并撤销尚未到期的卡住判定；按钮自然恢复可用时立即禁用重置入口。原站按钮可能被替换，观察器要重新定位当前书单的按钮，并清理旧节点监听。

五连任务因卡住停止时，先清除工具自身的忙碌锁并记录失败；若原站按钮仍不可用，五连入口不得再次发起点击，改由可用的重置入口承接恢复。用户点击重置入口时重新核对同一书单、同一次卡住事件、按钮仍不可用且没有新进展；条件失效就无操作地禁用入口。条件仍成立则**仅尝试一次**恢复原站按钮上可核实的禁用属性/状态，再按原站按钮的实际可用性更新五连入口；不自动再点 Show more、不重试请求、不改书卡或站点私有状态。一次重置后本次卡住事件不再反复提供重置；必须观察到新的一次有效点击才能再次启用。

这是尽力恢复按钮的 UI 可用性，不保证原站内部的加载锁已解除，也不保证后续请求成功。不得仅凭按钮外观宣称修复成功；若按钮的可核实 DOM 状态仍不可用或站点重新禁用，显示「无法恢复，请刷新页面」一类明确提示。恢复后的提示也应提醒用户：原请求可能仍在处理，立即再次点击可能重复加载。实现前需在已登录真实页面核实原站按钮实际使用的禁用属性/状态；未验证的镜像或无法确认的禁用机制不得猜测、清除任意类名、调用私有接口或自动发请求。所有状态、监听器和计时器只在当前书单页有效，路由变化、`pagehide` 和重新加载时清理；重置可用状态不持久化。新增文案纳入十种界面语言。

## 批量开页授权提示

「打开当前视图的所有图书页面」不因当前域名尚未授权而灰掉，也不再在按钮下方写「在设置中启用」。空闲时点击先检查逐域名授权：若未启用，只显示一个可键盘关闭的本工具信息弹窗：「该功能默认禁用，请到设置菜单中打开。」弹窗只有关闭按钮，不含即时启用入口，也不会打开任何书页。若已启用，再执行原有筛选就绪、目标存在、`GM_openInTab` 可用等安全检查；全部满足时才进入原有两次确认。其他安全条件不满足时仍不得开页，使用现有原因提示或单按钮信息弹窗说明；两次风险确认不得用于无效目标。任务忙碌或源书单失效时可以禁用按钮，防止并发操作。原有批量开页执行结果仍可在其下方显示；本次只取消 Show more 的下方状态段落。

## 自动化按钮视觉状态

可用按钮被鼠标按住或触屏按下时使用反色，松开即恢复；任务正在执行时保持反色，结束恢复。浅色模式为深蓝背景、白字，深色模式为浅蓝背景、深色字；颜色也须符合高对比度模式，不单靠颜色传达「运行中」。执行失败后按钮恢复正常背景并显示深红文字；深色模式用浅红文字，不能使用纯 `#FF0000`。失败态保持到下一次启动该任务或页面离开；用户主动取消确认不算执行失败。Show more 的超时或调用错误、批量开页中实际提交失败均进入失败态；正常到达书单末尾和用户取消确认不进入失败态。累计失败数 `Y` 不因后续一次成功而清零；红色只反映最近一次任务是否失败。收藏「开发中」按钮保持禁用，不伪装为可按下或运行中。键盘触发保留可见焦点与等价状态，`prefers-reduced-motion` 下无依赖动画的提示。

## 实现与验收重点

继续使用现有单文件脚本和存储字段，重排 DOM 但不复制一套筛选逻辑。三个配置面板只编辑 `settings` 的现有对应字段；所有筛选器仍由统一的 `scheduleRefresh`/`compileFilters` 处理。全局/逐域名偏好范围不变。新增翻译键必须在十个语言包齐全，语言切换即时更新已展开配置、按钮状态、弹窗与关于文本，不重建表单或丢失未提交输入。

先写失败测试，再实现。自动化测试至少覆盖：旧偏好迁移；全局扳手和三齿轮的互斥展开与点击不串扰；配置即时生效/文本冲刷；十语言完整性；新文案与无障碍标签；Show more 初始、运行、5 秒警告与倒计时、进展后恢复、连续 10 秒无进展停止、累计 5→10、失败字段仅在大于零时出现、末批不足 20 不计失败、点击抛错计失败、刷新后归零；手动原站点击也能触发卡住检测但不污染工具累计数；重置入口正常禁用、只在同一次有效点击后的卡住状态启用、用户手动触发一次且不会自动点站点按钮、旧书单/替换按钮/迟到的新书卡不能被错误重置；未授权批量开页只出现可关闭信息弹窗且零开页，授权后仍必须两次确认；任务忙碌/无效目标安全门控；按压、运行、失败、深色与高对比度样式。运行全套 `node --test`、`node --check booklist-enhancer.user.js`、`git diff --check`。

真实浏览器仍须分别验收 Chrome、Firefox、Edge 搭配 Tampermonkey：鼠标和键盘操作、浅色/深色/高对比度、窄视口与 200% 缩放、原站下载状态迟到、Show more 分批追加、实际禁用机制与手动重置，以及批量开页的模拟目标。无法在真实站点重现卡住时，只能标记重置能力「本地夹具通过、真实站点未验证」，不能由 Node 测试推定真实按钮已修复。未实际验收的组合标为「未验证」。
