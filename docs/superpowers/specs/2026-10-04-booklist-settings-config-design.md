# Z-lib Booklist Enhancer：设置、筛选配置与自动化反馈设计

状态：根据 2026-10-04 的需求和随后关于失败次数的补充整理，待用户审阅；本文不表示功能已经实现。现有 v3 行为以 [v3 设计](./2026-10-04-booklist-enhancer-v3-design.md)为基线。

## 目标与边界

让用户一眼区分工具的全局设置（setting）与每个筛选器的规则配置（configuration）；信息显示开关不增加配置。自动化按钮直接承载运行状态和 Show more 的累计点击结果，不再用 Show more 按钮下方的状态段落。保留现有格式、下载状态、年份筛选语义、即时生效规则、下载等待门控、批量开页两次确认和收藏「开发中」行为。现有 `zble-settings-v2` 与逐域名偏好继续有效，不清空用户已选规则。

本版仍是一个无需构建的 Userscript，版本递增为 `3.1.0-dev`；所有新增工具文案覆盖现有十种界面语言。浏览器真实验收未完成前保留 `-dev`。

## 设置与配置的划分

标题栏右上角原齿轮改为一致的单色扳手 SVG，名称/提示为「全局设置」。扳手只展开全局设置：界面语言、本站启动提示、本站批量开页授权、重置浮窗位置、镜像 User matches 说明，以及「关于」。关于栏目用一句话介绍本项目，例如「为 Z-Library 书单提供灵活筛选、信息显示和自选自动化操作。」；开发者和 GitHub 暂显示本地化的「待填写」纯文本，不创建虚假链接或占位 URL。

三个筛选器的文案旁各有独立齿轮 SVG 按钮，分别展开本条下方的内联配置：

| 筛选器 | 配置内容 |
| --- | --- |
| 文件格式 | PDF、EPUB、AZW3、MOBI、其他全部、自定义多选；自定义文本框及原有提示 |
| 下载状态 | 仅未下载／仅已下载 |
| 年份 | 最小年份、最大年份、显示年份缺失的书籍、输入生效提示 |

点击任一配置齿轮只展开/收起配置，不切换旁边的筛选开关；筛选开关只改变是否参与筛选。下载状态尚未取回、对应筛选开关置灰时，配置齿轮仍可打开以预设规则。最多展开一个配置区域：打开另一项或全局设置时先关闭当前项；再次点击同一按钮则收起。折叠整个面板时暂存当前展开状态，不改变筛选规则。配置和全局设置在视觉上用不同标题、边框/底色区分；齿轮/扳手均有 `aria-label`、`aria-controls`、`aria-expanded` 与可见键盘焦点。文本输入沿用停顿约 250 毫秒或回车生效，并在收起对应配置时冲刷未提交输入。所有开关与选择仍即时生效。

信息显示区仅保留五个开关、没有齿轮。文案改为「文件格式标签」「书籍语言（页面自带）」「书籍年份（页面自带）」，长书名和长作者名文案不变。十种语言均表达“页面自带”与“工具增补标签”的区别；标签的实际显示/隐藏行为不变。

## Show more 按钮状态与累计计数

初始文案仍为「连点 5 次 Show more」。每次任务执行时显示「[运行中] 连点 5 次 Show more」；任务停止后显示「连点 5 次 Show more [已点 X 次]」。如果累计加载失败次数 `Y > 0`，改为「连点 5 次 Show more [已点 X 次，失败 Y 次]」；`Y = 0` 时完全不显示失败字段。`X` 是当前书单页面内本工具对原站 Show more 按钮实际发出的点击尝试总数，不是启动自动化的次数或成功加载批次数；`Y` 是这些点击中未能完成该轮加载的次数。二者跨同一页面上的多次自动化运行累计，刷新、离开或切换书单后归零，不持久化。

一次点击在观察器建立并即将调用原站 `click()` 时记入 `X`；若该次调用抛错，或点击后该批等待 20 秒仍未完成，记入 `Y`。按钮在点击前已不可用、用户导航离开/关闭页面、中途取消，以及按钮消失且末批不足 20 本但已稳定并到达书单末尾，都不算「加载失败」。若脚本无法明确判断结果，保守停止且不虚构成功或失败。现有 `runShowMoreFive` 须单独报告实际点击尝试和失败批次，不能把现有的 `completed` 批次数当作点击次数。移除 Show more 按钮下方的可见状态统计；失败原因可在按钮的 `title`/无障碍描述中给出，不能用 `Y` 掩盖原因。原站 Show more 上附加的页数估算仍保留，与此累计计数相互独立。

## 批量开页授权提示

「打开当前视图的所有图书页面」不因当前域名尚未授权而灰掉，也不再在按钮下方写「在设置中启用」。空闲时点击先检查逐域名授权：若未启用，只显示一个可键盘关闭的本工具信息弹窗：「该功能默认禁用，请到设置菜单中打开。」弹窗只有关闭按钮，不含即时启用入口，也不会打开任何书页。若已启用，再执行原有筛选就绪、目标存在、`GM_openInTab` 可用等安全检查；全部满足时才进入原有两次确认。其他安全条件不满足时仍不得开页，使用现有原因提示或单按钮信息弹窗说明；两次风险确认不得用于无效目标。任务忙碌或源书单失效时可以禁用按钮，防止并发操作。原有批量开页执行结果仍可在其下方显示；本次只取消 Show more 的下方状态段落。

## 自动化按钮视觉状态

可用按钮被鼠标按住或触屏按下时使用反色，松开即恢复；任务正在执行时保持反色，结束恢复。浅色模式为深蓝背景、白字，深色模式为浅蓝背景、深色字；颜色也须符合高对比度模式，不单靠颜色传达「运行中」。执行失败后按钮恢复正常背景并显示深红文字；深色模式用浅红文字，不能使用纯 `#FF0000`。失败态保持到下一次启动该任务或页面离开；用户主动取消确认不算执行失败。Show more 的超时或调用错误、批量开页中实际提交失败均进入失败态；正常到达书单末尾和用户取消确认不进入失败态。累计失败数 `Y` 不因后续一次成功而清零；红色只反映最近一次任务是否失败。收藏「开发中」按钮保持禁用，不伪装为可按下或运行中。键盘触发保留可见焦点与等价状态，`prefers-reduced-motion` 下无依赖动画的提示。

## 实现与验收重点

继续使用现有单文件脚本和存储字段，重排 DOM 但不复制一套筛选逻辑。三个配置面板只编辑 `settings` 的现有对应字段；所有筛选器仍由统一的 `scheduleRefresh`/`compileFilters` 处理。全局/逐域名偏好范围不变。新增翻译键必须在十个语言包齐全，语言切换即时更新已展开配置、按钮状态、弹窗与关于文本，不重建表单或丢失未提交输入。

先写失败测试，再实现。自动化测试至少覆盖：旧偏好迁移；全局扳手和三齿轮的互斥展开与点击不串扰；配置即时生效/文本冲刷；十语言完整性；新文案与无障碍标签；Show more 初始、运行、累计 5→10、失败字段仅在大于零时出现、末批不足 20 不计失败、超时及点击抛错计失败、刷新后归零；未授权点击只出现可关闭信息弹窗且零开页，授权后仍必须两次确认；任务忙碌/无效目标安全门控；按压、运行、失败、深色与高对比度样式。运行全套 `node --test`、`node --check booklist-enhancer.user.js`、`git diff --check`。

真实浏览器仍须分别验收 Chrome、Firefox、Edge 搭配 Tampermonkey：鼠标和键盘操作、浅色/深色/高对比度、窄视口与 200% 缩放、原站下载状态迟到、Show more 分批追加以及批量开页的模拟目标。未实际验收的组合标为「未验证」，不能由 Node 测试推定通过。
