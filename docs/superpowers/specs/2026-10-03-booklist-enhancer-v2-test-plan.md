# Z-Library 书单增强 v2：测试与验收方案

状态：已执行一部分 v2 验证，**真实站点脚本管理器端到端验收和 375px 窄屏验收尚未完成**。对应设计为 [v2 设计规格](./2026-10-03-booklist-enhancer-v2-design.md)；`1.0.2-dev` 的历史验证仍见仓库根目录的 `TEST_PLAN.md`，不能移作 v2 通过证明。

## 测试原则与夹具

先为新增行为写失败测试，再实现最小改动，最后运行全套现有与新增测试。纯逻辑测试覆盖年份规则、设置迁移、单次筛选结果和进度公式；DOM 夹具覆盖开放 Shadow DOM 书卡、桌面/移动元信息、长书名、站点原生 Show more 的 `onclick`、动态追加/替换、下载映射三态。浏览器夹具必须包含四列桌面和约 375px 窄屏。自动化夹具不向真实站点发书籍或下载请求。

## 自动化测试矩阵

| 领域 | 必须验证的输入与结果 |
| --- | --- |
| 域名与启动门控 | 六个指定 HTTPS 域名的 `/booklist/*` 可匹配；`.biz`、主页和其他路径不匹配；用户自加域名若非书单结构则不创建界面或改 DOM。 |
| 旧设置迁移 | 旧 `showFormat`、格式集合、下载规则及开关继续生效；新语言/年份显示默认开，完整书名/年份筛选/显示缺失年份默认关；坏存储值安全回退。 |
| 主界面与设置 | 两个分类、七个主开关的文案/默认值/键盘标签正确；齿轮只控制设置显隐，设置区明显独立；开关与下拉即时生效，文本停顿后自动应用，Enter/失焦立即应用，收起设置时不丢待处理输入。 |
| 规则摘要 | 格式单选/多选/自定义、下载两种规则、年份闭区间/单边区间/单年分别显示正确；空规则显示“请手动设置”，无效范围显示“设置冲突”；下载等待时摘要不冒充筛选已启用。 |
| 元信息显示 | 桌面与移动 `.idle` 的语言/年份四种开关组合均正确；`year="0"` 不显示伪年份；格式标签、悬停区、原链接不丢；反复切换及卡片替换后原文可精确恢复、无重复节点。 |
| 长书名 | 关闭时保持原两行；开启后实际长标题完整显示且卡片高度增长；关闭恢复。四列中相邻卡片、下一行和 Show more 不重叠；375px 视口可阅读、可点击。 |
| 年份规则 | 两端空时 fail-open；仅下限/仅上限/端点相等/闭区间正确；`year=0`、缺失或无法解析默认排除，有效范围内打开例外后显示；例外本身不构成范围。负数、零、非整数、非数字、超 9999、最小值大于最大值提示冲突并暂停该筛选；原输入保留供修正。 |
| 统一筛选 | 格式、下载、年份三项取交集；一次设置事件只排入一次合并刷新，同一轮只枚举一次真实书卡；某项等待/冲突仅暂停该项，其他项继续生效；站点原生隐藏不混入本工具 Y。 |
| 统计卡 | 任一筛选开时（包括规则为空、冲突或等待）出现于最后一张可见书卡后，含 X/Y/T；Y 只计实际生效的规则；零匹配时仍可见；不是 `z-bookcard`，不计入 X、Y、下载查询或 Show more 批量；全部筛选关时移除。总数缺失/矛盾及规则暂停的提示准确。 |
| Show more | 保留原 `.page-load-more`、`.content` 与点击处理；进度文字只插入一次，0/20/40/47 等实际加载量给出正确约展开次数和页数，0 条时不出现“第 0 页”；站点按钮内容变化/替换后恢复附加文字；原按钮消失时页数提示也消失，且不产生备用进度条。 |
| 下载门控与错误 | `marksLoaded` 非空映射仍按旧规则启用，空映射/失败/30 秒超时不误判；转圈、暂停和错误改为就地提示，超时或失败建议刷新页面或检查登录，旧状态栏不存在；格式位置不兼容时仅对应功能提示，不破坏原卡片。 |
| 折叠与拖动 | 初始展开；折叠后仅标题、齿轮、折叠按钮可见，筛选持续生效；按钮图形、`aria-expanded` 同步；齿轮在折叠状态下可展开设置。拖动与点击分离，停靠最近视口边缘并不越界；位置恢复和窗口缩放钳制正确；重置立即有效。 |
| 稳定性与隐私 | 多次 Show more、排序/搜索替换、设置连点、拖动和布局变化不产生 MutationObserver 循环；脚本存储不含书籍身份、令牌、标题、真实点击次数或阅读断点；无外部请求。 |

## 浏览器手动验收

1. 本地夹具先运行现有全部测试与新增测试，再用浏览器观察桌面四列和 375px 窄屏：格式徽标、语言/年份开关、含至少六行的长标题、统计卡位置、Show more 原点击、设置即时生效、折叠和四边停靠。检查实际元素边界与焦点顺序，不仅看文本断言。
2. 在用户提供的已登录 `1lib.sk` 书单上以脚本管理器安装后的实际脚本验收：初始 20 本、Show more 增量、非 20 整数批、格式/年份交集、下载等待/恢复、原生排序/搜索、全部筛选关时的恢复；不下载书籍、不修改书单。
3. 对新加的 `z-library.im`、`z-lib.fm` 和已有其他域名，至少各打开一张实际书单核对结构检测、语言/年份属性、Shadow DOM、Show more 与登录状态；只打开首页不能视为兼容验收。无法访问或未登录的域名明确标为未验证，不推定通过。
4. 在已加载到底、Show more 消失的受控夹具中确认页数进度同步消失；若仍开启筛选，统计卡仅继续显示 X/Y/T，不另补页数信息。

## 发布门槛与记录

语法检查、全量自动化测试、本地端到端布局检查以及至少一个真实已登录书单的关键路径通过后，才可把 v2 标为可用。每次记录脚本版本、域名、日期、视口、设置、预期/实际结果和未验证项；不得记录账号令牌、完整私有链接或下载映射。发现书卡结构差异时先保守降级并提示，不能用另一域名的通过结果替代。本方案本身不是测试通过记录。
