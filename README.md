# Z-lib Booklist Enhancer

当前可安装脚本为 [booklist-enhancer.user.js](./booklist-enhancer.user.js)，版本 `3.0.1-dev`。它只处理当前已加载的书单，不保存书籍链接、阅读断点或下载映射；`-dev` 表示尚未完成 Chrome、Firefox、Edge 与真实站点的逐项验收。

## 安装与更新

安装 Tampermonkey 后新建用户脚本，将 `booklist-enhancer.user.js` **完整内容**粘贴并保存。若已有旧版，替换旧脚本并停用重复副本；更新本地文件后也要再次粘贴完整内容，脚本目前没有自动更新地址。刷新网页后生效，原有 `zble-settings-v2` 显示与筛选偏好会保留。

内置 `@match` 为以下六站的 **HTTPS 全站**页面：`z-lib.sk`、`z-library.sk`、`1lib.sk`、`libb.la`、`z-library.im`、`z-lib.fm`。书单页显示完整工具；这些站的其他页面只在每个域名的当前标签页会话中显示一次 10 秒提示，可关闭或按域名关闭后续提示。提示的「点击试用」指向 `/booklists`；已经在该页时不显示自身链接。脚本不在 iframe 中运行。

其他镜像请先自行核实可信性，再到 Tampermonkey 的本脚本设置中手动添加精确 [User matches](https://www.tampermonkey.net/faq.php?q=Q103)，例如 `https://your-mirror.example/booklist/*`（替换为实际域名）。未知镜像仅在 URL 为 `/booklist/…` 且页面结构符合书单特征时启动工具；非书单页静默。脚本不能自行更改 `@match`；结构匹配也**不能证明镜像安全**。不要用全站通配匹配。

## 使用

- 「筛选器」按文件格式、下载状态、出版年份取交集。格式首次不预选；空规则或冲突年份规则会提示并暂停该项，不会误隐藏整页。年份缺失默认排除，可在设置中允许显示。
- 「信息显示」可固定格式标签，显示/隐藏语言与年份，并展开超长书名或作者名。展开会撑高信息区和书卡。
- 启用筛选器后，末尾增加三项统计卡：已加载、本工具筛选后、书单总数。Show more 后附加按每 20 本估算的页数进度；它不是实际点击历史或可恢复的断点。原站移除按钮后，进度也消失。
- 「自动化（beta）」中的「连点 5 次 Show more」每轮等到新增 20 张真实书卡并稳定后才点下一次；不足 20、本轮超时或按钮消失会保守停止。真实站点的分批规律尚未验收，不建议依赖它处理重要书单。
- 「打开当前视图的所有图书页面」默认按域名禁用，须在设置中手动授权。它只取当前加载、经筛选且实际可见的同源 `/book/` 链接，经两次确认后通过 `GM_openInTab` 逐本向浏览器提交后台开页请求。可能造成大量标签页、卡顿、内存占用或站点限流；提交成功不代表页面已加载。没有 50 本上限、批量撤回、自动重试或持久打开历史。同页再次执行会额外警告可能重复打开。请先用少量条目试验浏览器行为。
- 「批量加入收藏」本版只有禁用的“开发中”入口，不会调用原站收藏动作。

齿轮中的设置即时生效；文本输入停顿约 250 毫秒后应用，也可按回车。界面语言默认跟随浏览器/系统，支持英语、简体中文、繁体中文、法语、德语、俄语、日语、韩语、西班牙语和巴西葡萄牙语，无法匹配时回退英语。按域名保存启动提示与批量开页授权；其余显示、筛选和语言设置为全局偏好。单击或双击标题栏均可收起/展开面板；标题栏也可拖动并吸附屏幕边缘，设置中可重置位置。界面支持深色模式、减少动画和高对比度 CSS。

下载状态依赖站点异步记录。尚未确认时该筛选器置灰并暂停；30 秒后提示刷新或检查登录。空下载映射与请求失败无法可靠区分，因此脚本**不会**把未知状态当作未下载。其他功能仍可使用。
